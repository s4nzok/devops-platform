# DevOps Platform

A production-style DevOps project built by progressively applying real-world DevOps practices using:

- Docker
- Kubernetes
- Jenkins
- Ansible
- Terraform
- AWS

---

## Goal

Build and deploy a production-ready platform while documenting every milestone from containerization to cloud deployment.

---

## Roadmap

- Docker Foundation
- Kubernetes Platform
- CI/CD with Jenkins
- Infrastructure Automation with Ansible
- Infrastructure as Code with Terraform
- AWS Deployment
- Monitoring
- Production Release
